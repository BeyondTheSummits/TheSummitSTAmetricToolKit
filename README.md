🏔️ The Summit STA Metric ToolKit

What started as a simple calculator grew into a fully modular mathematics toolkit containing 100 advanced calculations spread across 11 custom Python modules and the main code file.

This project was built using Python and focuses on clean architecture, reusable code, input validation and modular programming.
